# きらりフェスタQUEST (kirari-festa-quest)

「かまがや市民活動・男女きらりフェスタ2026」向けのスマートフォン参加型体験ミッションラリーアプリケーションです。

## 🚀 システムの特徴
- **低コスト・サーバーレス**: データベースやバックエンドサーバーを必要とせず、GitHub Pagesを利用して**完全無料**で迅速に公開・運用可能です。
- **安心のプライバシー設計**: ログイン機能や個人情報（氏名・連絡先等）の入力欄を一切設けていません。参加者の進捗状況はスマートフォンのブラウザ内（`localStorage`）にのみ安全に保存されます。
- **優れた操作性・アクセシビリティ**: スマートフォン画面幅（375px〜）に完全最適化。押しやすい大きなボタンや、幅広い世代が読みやすい文字サイズ・コントラストを適用しています。

## 📂 構成ファイル一覧
- `index.html` : 企画トップページ（概要・注意事項への導線）
- `howto.html` : 参加手順・遊び方説明ページ
- `notice.html` : 安全利用・免責事項・個人情報に関する案内ページ
- `missions.html` : 10個の仮想ブースを網羅したミッションカード一覧
- `mission-detail.html` : 各ミッションの詳細情報および合言葉入力・判定機能
- `stamp.html` : スタンプ獲得状況（10個のマス目）、称号判定、および5個以上達成時の「デジタル認定証」表示機能
- `assets/css/style.css` : お祭りらしく明るい配色をベースにした共通デザインシート
- `assets/js/missions.js` : 全10ブースのデータ（ID、ブース名、難易度、クリア条件、合言葉など）を定義するファイル
- `assets/js/app.js` : ローカルストレージ制御、データ初期化（リセット）、称号ロジック等のコア共通処理

## 🛠 実データへの差し替え方法（カスタマイズ）
実際のイベント出展団体やミッション内容、合言葉（キーワード）が決定した段階で、 `assets/js/missions.js` の中身をテキストエディタ等で書き換えるだけで、すべての画面（一覧、詳細、スタンプ判定）へ自動的に実データが反映されます。

## 💻 GitHub Pages での公開手順
1. 本パッケージ（解凍したフォルダ一式）をご自身のGitHubリポジトリにPushします。
2. リポジトリの `Settings`（設定）タブを開き、左メニューから `Pages` を選択します。
3. **Build and deployment** の Source にて `Deploy from a branch` を選択し、ブランチを `main`（または `master`）に設定して `Save` をクリックします。
4. 数分待つと上部に公開URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）が発行されます。
5. このURLをQRコード化し、会場の案内チラシやPOPに掲載することでミッションラリーを開始できます。
